# 홈드랍 데모 규칙 (시연용)

- 작성 : 팀 작성 데모 자료
- 작성일 : 2026-11-12
- 성격 : 시연용 데모 값입니다. 실제 홈드랍 서비스의 요금·규칙이 아닙니다. 실제 기준은 인천국제공항공사와 항공사의 협의가 필요합니다.
- 문의 : 시연용 자료라 별도 문의처가 없습니다.

## 요금 (데모)
- 기본 20,000원 (캐리어 1개)
- 캐리어 1개 추가마다 10,000원
- 28인치 이상 대형 캐리어는 1개당 5,000원 추가
- 예) 캐리어 2개 : 30,000원
- 이 요금은 데모 값이며, 이지드랍 요금(수하물 1개당 35,000원)과 다릅니다.

## 예약 규칙 (데모)
- 한 번에 캐리어 8개까지 예약할 수 있습니다.
- 수거 희망 시각은 항공편 출발 8시간 전까지만 정할 수 있습니다.
- 예약이 끝나면 예약 번호(태그 번호)를 발급합니다.
- 수거 30분 전에 기사님이 연락합니다.

## 항공편 확인 범위 (데모)
- 항공편 정보는 오늘부터 6일 뒤까지만 확인합니다.
- 그 밖의 날짜는 「확인 필요」로 안내합니다.
- 데모는 항공편 번호가 실제로 있는지 확인하지 않습니다.

## 수거 금지물품 (데모)
홈드랍으로 맡길 수 없는 물품입니다.
- 보조배터리·전자담배·라이터 : 직접 휴대해야 합니다.
- 현금·귀금속·노트북 등 귀중품
- 가스·인화성 물질
- 기내 반입·위탁 가능 여부 같은 항공 보안 기준은 인천공항 제한물품 안내와 각 항공사 기준을 따릅니다.

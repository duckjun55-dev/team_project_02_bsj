# 홈드랍 시범 운영 계획 보도 요약

- 출처 : 뉴스핌 보도, 2025-05-30 (https://www.newspim.com/news/view/20250530000582)
- 확인한 날 : 2026-11-05
- 성격 : 언론 보도를 요약한 것입니다. 2025년 5월 시점의 계획이라, 실제로 시행됐는지는 확인하지 못했습니다. 확인 필요입니다.
- 문의 : 인천국제공항공사 (연락처는 이 보도에 없어 확인 필요)

## 홈드랍이란
사전 예약한 승객의 국내 자택·숙소로 전문요원이 방문해 체크인과 수하물 수거를 해 주는 서비스입니다.

## 계획된 절차
1. 모바일 체크인을 마친 여객이 출발 2일 전까지 예약합니다.
2. 사업자인 롯데글로벌로지스가 예약 내역을 확인하고 방문 계획을 세웁니다.
3. 출발 1일 전, 미리 출력한 수하물 태그와 함께 방문해 위탁수하물을 수거합니다. 여객은 본인 확인과 보안 절차를 위해 웹·모바일 탑승권을 보여 줘야 합니다.
4. 수거한 수하물은 지정 장소에 보관합니다. 보안 시설을 갖춘 인스파이어 리조트를 유력하게 검토 중이라고 보도됐습니다.

## 계획된 범위
- 빠르면 2025년 9월 시범 운영, 서울 서초구 일대부터 시작하고 강남권에서 서울 다른 지역으로 넓힐 계획이라고 보도됐습니다.
- 이용 가능한 출발 시간대는 제1여객터미널 오전 11시~오후 11시, 제2여객터미널 오전 10시~오후 10시입니다.
- 미주 노선은 미국 TSA 보안 규정 때문에 이용이 어렵습니다.
- 공사는 2025년 6월 중 보안 실증사업(PoC)을 마치고 8월에 사전 검증을 한 뒤 9월에 시범 운영한다는 방침이었습니다.

홈드랍 예약·안내 챗봇 시스템 설계도

요청은 위에서 아래로 — 브라우저 화면 → 서버 → 외부 서비스(AI · 공공데이터) 순서로 내려갑니다.

AI 순서와 대비책

  • Claude 를 먼저 부르고, 키 없음·오류·시간 초과면 Groq → Gemini
  • 모두 실패하면 AI 없이 규칙 모드로 같은 예약 흐름 진행
  • 답마다 「답한 AI」를 화면에 표시

답변과 데이터 표시

  • 답은 답변참고문서 근거로만, 근거 문서 이름을 붙임
  • 문서에 없으면 모른다고 하고 문의처 안내
  • 「실시간 · 시연 값 · 확인 필요 · 데모」로 출처 구분

실행 환경 · 키 · 개인정보

  • 배포는 Vercel 함수, 로컬은 server.js 로 실행
  • API 키는 서버에만(로컬 .env · Vercel 환경 변수), 화면에는 없음
  • 예약은 이용자 브라우저에만 저장
  • 실제 개인정보 입력 금지 안내
